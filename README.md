# SE Ranking Research Studio 🚀

A high-performance full-stack SEO, GEO (Generative Engine Optimization), and AI Visibility platform built with Next.js 16, TypeScript, Tailwind CSS, Recharts, and Lucide Icons.

![SE Ranking Studio](https://seranking.com/blog/wp-content/uploads/2023/11/SE-Ranking-Brand-Kit.png)

## ✨ Core Features & Modules

- **AI Search & GEO Visibility Suite**: Monitor visibility, sentiment, and share-of-voice across ChatGPT, AI Mode, Gemini, Perplexity, and Claude.
- **Organic Keyword & Rank Tracker**: Real-time position tracking across global search engines, SERP feature detection, and historical rank trend curves.
- **Competitive & Domain Intelligence**: Reverse-engineer competitor keywords, organic search share, and market gaps.
- **Agency Pack & White Label**: Custom-branded client reporting, automated audits, lead generation widgets, and scalable team seats.
- **Pixel-Perfect SE Ranking Landing Experience**:
  - Top Dismissible Green Announcement HelloBar
  - Exact 7-item Navigation Menus with Suite Switcher
  - Hero Section with in-place smooth rotating social proof avatar carousel (`Trusted by 40,000+ agencies`)
  - Continuous Infinite Auto-scrolling Partner Logos Marquee (`soapbox`, `Nex Brand`, `Tailor Brands`, `Wiser IT`, `Kaida`, `neary hayes`)
  - Complete AI SEO Platform with Interactive Engine Mockups
  - 5 Stat Cards + Official G2 Shield Badges
  - Brand Visibility Across Ecosystem (SE Ranking, SE Visible, Planable interactive cards)
  - Agency Pack Interactive Showcase
  - Testimonial Carousels & Case Studies
  - Official 3-Column Spacious Footer with App Store & Google Play badges, plus interactive multi-language selector.

## 🛠️ Tech Stack

- **Framework**: Next.js 16 (App Router + Turbopack)
- **Language**: TypeScript
- **Styling**: Tailwind CSS & Vanilla CSS
- **Charts & Data Visualization**: Recharts
- **Icons**: Lucide React
- **Avatars & Assets**: Vector SVGs with high-res portrait fallbacks

## 🚀 Getting Started

### 1. Clone & Install Dependencies

```bash
git clone https://github.com/MamtaYdvTech1/SE-Ranking.git
cd SE-Ranking
npm install
```

### 2. Start the Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to explore the platform.

### 3. Demo Login Credentials (Work Office Email)

For instant access across local development and Vercel deployments:

| Field | Value |
|---|---|
| **Work Office Email** | `admin@seranking.com` |
| **Password** | `AdminPassword123#` |
| **Default Active Project** | `https://www.workcomposer.com/` |

> [!NOTE]
> All authentication and dashboard routes operate with automatic serverless fail-safe session fallbacks, ensuring zero `500` errors on Vercel even without setting an external database connection string.

### 4. Production Build & Deployment

```bash
npm run build
npm run start
```
